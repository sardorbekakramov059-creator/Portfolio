## Loyiha haqida

Bu — Sardorbek Akramovning shaxsiy portfolio veb-sayti. Sayt orqali tashrif buyuruvchilar dizayner bilan tanishishi, uning xizmatlari va loyihalarini koʻrishi hamda u bilan tezda bogʻlanishi mumkin.

Sayt **bitta sahifa (Single Page)** koʻrinishida qurilgan va ichida **6 ta boʻlim** bor. Boʻlimlar orasida oʻtganda sahifa qayta yuklanmaydi — almashinuv silliq animatsiya bilan amalga oshadi.

## Sahifalar

| Boʻlim | Havola | Mazmuni |
|---|---|---|
| Bosh sahifa | `#home` | Salomlashuv, yozilib turuvchi kasb nomlari (*Product Designer*, *UI/UX dizayner*, *Veb dizayner*), 3D shakllar, «Portfolio» va «Menga yozing» tugmalari, harakatlanuvchi yozuv lentasi |
| Men haqimda | `#about` | Qisqa tanishuv va loyihalar kartochkalari (mobil ilova dizayni, veb-sayt dizayni, landing sahifa, brend uslubi) |
| Aloqa | `#contact` | Xabar yuborish formasi, telefon raqami va WhatsApp tugmasi |
| Xizmatlar | `#services` | UI/UX dizayn, Veb dizayn, Landing sahifa |
| Rezyume | `#resume` | Ish tajribasi (vaqt chizigʻi koʻrinishida) |
| Blog | `#blog` | Dizayn jarayoni, foydalanuvchi tajribasi, ranglar va shriftlar haqidagi maqolalar |

## Ishlatilgan texnologiyalar

| Texnologiya | Qayerda ishlatilgan |
|---|---|
| **HTML5** | Sahifa tuzilmasi, semantik teglar (`nav`, `main`, `section`, `footer`) |
| **CSS3** | CSS oʻzgaruvchilari, Grid va Flexbox, `@keyframes` animatsiyalar, 3D transformatsiyalar, `backdrop-filter`, media-soʻrovlar |
| **JavaScript (Vanilla)** | Boʻlimlar almashinuvi (`#` orqali), yozilish effekti, 3D ogʻish, rejim almashtirish, aloqa formasi |
| **Three.js (r128)** | Bosh sahifadagi 3D shakllar (WebGL) |
| **SVG** | Bosh sahifadagi shaxs tasviri |
| **Intersection Observer API** | Skroll qilinganda paydo boʻluvchi animatsiyalar |
| **Google Fonts — Outfit** | Sayt shrifti |
| **Figma** | Dizayn namunasi |
| **Netlify** | Saytni internetga joylashtirish (hosting) |
